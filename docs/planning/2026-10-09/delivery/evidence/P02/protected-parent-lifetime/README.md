# Protected role lifetime after host death

This is bounded P02 evidence, not task or phase acceptance. The kernel entry point now requires the supervisor-owned EOF pipe and uses runtime.ParentLifetime to cancel its role when the launcher dies. The optional inherited lock descriptor stays open until actual process exit. No application messages travel on the lifetime pipe.

The real test builds a static kernel, verifies a release signature against a separately trusted fixture key, starts four independently supervised protected processes against a real disposable NATS broker, and waits for actual ready status. It kills only the exact host subprocess that the test started. Previously opened Linux pidfds then observe all four child exits without signalling children. Each retained lock inode can be acquired after those exits. The dead host cannot perform its own Wait/reap; this proof records actual child exit and descriptor release, not host cleanup after death.

The first affected run exposed the same pre-existing Go Root symlink-open issue independently found by the root reviewer and changed while that run was in progress. Its raw failed result and source bytes are preserved as historical, unstable evidence. On the corrected frozen source, the exact previously failing test passed first, then the affected kernel and command race suites passed 144 named entries, no failures or skips, with all recorded source hashes unchanged. The earlier focused host-death pass is historical.

The final source, raw JSON event streams and environment details are preserved byte for byte. This qualifies only the recorded native Linux host through WSL. It does not qualify Darwin descriptor execution, production installer enrollment, general child descendants, a same-user hostile sandbox, full L04 status or the whole bootstrap. Credentials, generated broker configs, private broker logs and signing private keys are excluded. Historical actor and runtime evidence remains unchanged.
